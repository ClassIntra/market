# 拾光群岛 · 更新记录

## 4.1.0 · 玩法深度 × 开放世界

4.0.0 解决了「没压力」，4.1.0 解决「没朋友、没纵深」：采集要有节奏、
同学要能互动、世界要有尽头。

### 玩法深度（节奏与决策）
- **连击采集**：10 秒内连续采集累计 combo。×2 起头顶浮字，×4 起 toast
  带连击数、音效随连击升调，×8 金字加码；连击加成同时回一点火
  （快节奏本身就有奖励）。服务端权威计连击，防刷。
- **灯柱升级**：站在一级灯柱旁花 5 星屑升到二级 —— 光照半径 4.2→6.0 格、
  光柱更高更亮、黑暗层的洞更大。全班的灯越用越值钱。
- **送火**：点同学（或点菜单）送 1 枚星屑（6 格内），TA 头顶炸一圈金光。
  星屑第一次变成「可以给出去的东西」。

### 同学交互（点人即菜单）
- **点同学打开菜单**：头像名、称号、距离坐标；两个动作 ——
  **跟随 TA**（贪心寻步自动跟在身边，任何移动打断、卡住/30 秒自动停）、
  **送一枚星屑**。Journey 的牵手语义，换成提灯的旅程。
- **同学罗盘**：屏幕边缘一枚枚灯色光点指向屏外同学，尾迹指向感、
  越近越亮；正在跟随的人带金圈锁定。看不见 ≠ 不存在。
- **入岛 / 离岛广播**：有人进岛全班横幅「XX 来到了群岛」，
  离岛轻提示，本地名单即时归真。

### 开放世界的边界
- **世界边缘界标**：160×160 世界的四角立起呼吸的灯桩，
  隔着整片夜海也看得见 ——「尽头有灯」是开放世界的安全感。
- **边缘提示**：走近边界出现流动的虚线描边与语境提示
  「云海之外，什么都没有」；帮助面板补「同 / 界」两条。

### 修复
- `updateLight` 引用了未定义的 `surge`（应为 `state.surge`），
  暗涌订阅路径上会炸掉整个渲染循环 —— 沙盘逐帧验证抓出。

## 4.0.0 · 灯火

3.1.0 的问题是：这个岛「有内容，但没有压力」。
走到星屑上按一下 +1，再走到空地上按一下立灯 —— 全程零决策、零风险、零节奏。
你说「玩起来没意思」，对的是：它是一张会动的画，不是一个游戏。

这一版把「你手里还有多少火」变成唯一的资源，同时让它接管三件事：
血量、视野、货币。世界的样子会跟着你的火一起变。

### 灯火（新 · 核心）
- **火会自己烧**：走路 0.95/秒、站着 0.30/秒。站着也在暗，挂机不等于安全。
- **视野就是火**：满火能看 10 格，火只剩一成时只能看 4 格。
  四周压黑不是后期叠的一层暗角，是「你还能看多远」直接画在屏幕上。
- **灯柱是唯一补给**：站在点亮过的灯 6 格内回 4.2/秒。
  ⚠️ **别人的灯一样管用** —— 多人关系不是靠聊天建立的，是靠「谁在这里点过灯」。
- **点灯要烧自己的火**（-22）：你把自己的命换成一块永久的安全区。
- **雾灵**：火低于 34% 开始出现，最多 4 只，1.15~1.5 格/秒朝你漂。
  玩家 3.8 格/秒，**永远跑得掉** —— 它逼你走，不逼死你。碰到一次偷 9 点火。
- **火灭**：全黑昏迷 3 秒，醒来原地只剩 45 火。不传送、不扣星屑：
  代价是时间和位置，不是资产。

### 主线第一次被看见
- 顶栏「长夜」改成「长夜 · 3/10」。`/terrain` 从 3.0 起就一直在返回
  `stages`，前端从来没接住 —— 于是「全班一起把灯点到 100 根、把天光推到
  拾光之海」这条主线，在界面上一直是隐形的。
- 点灯提示改成「离「晨光初现」还差 7 根」，差 3 根以内换成另一句。

### 世界重做（地图 / 配色 / UI）
- **8 座正圆岛 → 复合岛形**：每岛 3~4 个偏移圆瓣，取所有瓣中最深的归一化深度。
  地峡、内湾、半岛自己长出来；沙环按深度切，半岛尖端窄、宽阔处宽。
  原先每座岛的半径只差 ±12%，高空看是八个圆。
- **内陆湖**：启明岛与萤火泽各一处（`LAKE`，不可走、不可点灯）。
- **村道**：启明岛原来是 44 格正交十字（80,66→80,110 / 58,88→102,88），
  俯视是一条一直通到画外的宽带 —— 「城镇骨架」没做出来，先做出来一条跑道。
  现在是主街 + 四条斜支路，路面 1.84 格。
- **沙岸与土径分开成两套色**：上一版 sand 通道借用 `pathLit`（暖米色），
  而沙环占陆地 27% —— 全画面面积最大的暖色是「没人点亮的沙子」，
  灯反而比不过它。现在沙是冷褐、土径是暖褐，暖色只属于光。
- **UI 去面板化**：顶部 HUD / 小地图 / 摇杆 / 动作簇 / 对话卡全部拆掉
  深色玻璃卡片 + 圆角 + 阴影（那是 2020 年移动端模板语言，贴在手绘夜空上
  属于另一个世界）。改用字距（0.18~0.22em）+ 字号层级立住。
  动作键从六个等大彩圆 → 一个主键 + 两列圆心对齐。
- **灯塔**：比例 1:1.65 → 1:3.9。之前画出来是水塔。补拱门漏光、护栏平台、
  竖窗框、锥顶顶针，光束改橙黄三层扇形（一层三角形无论怎么调都是「一块均匀的雾」）。

### 树：五次试错的记录
1. 6 个圆瓣 → 花椰菜
2. 11 个小瓣 → 葡萄串
3. 5 个等分瓣 → 梅花
4. 正弦叠加大振幅 → 海星；小振幅 → 圆盘
5. **3 个不对称叶扇（每个 = 3 个随机旋转的椭圆）+ 每团自带小块亮面** ✅

结论写在这里，免得下次再走一遍：
- **用几何圆拼不出有机形状** —— 交角只有固定几档，眼睛三秒读出「是拼的」。
- **贴着轮廓的连续亮边 = 湿石头高光的固定读法**。叶子给的是断开的亮斑。
- **树的色相必须和草地的色相不同**，不能只是更暗 —— 更暗的草地就是石头。

## 3.1.0 · 岛上有人

3.0.0 的岛上住着四个人，但他们只是「会走路的随机广播器」：从公共台词池里抽一句、
11 秒一次、说完就忘。玩家走过他们身边，什么也不会发生。
这一版把居民改成了有记忆的人，并把「这个世界里来过别人」变成能被看见、被听见的东西。

### NPC 对话（新）
- **走近 4 格自动开口**，不用点、不用按键。走到哪儿都有一个人先说话。
- **每人一套专属剧情**，按见面次数推进；进度落库（`shiguang_npc_talk`），
  换设备、隔一周回来，她还记得你聊到哪儿。
- **初见先说世界的真话**：这段时间几个人上过岛、上一个叫什么、
  他最后停在哪个坐标、全班一共点了多少盏灯、离下一阶天光还差几盏。
  数字全部现算，所以每一句都是真的 —— 这是「多人大世界」在没有人在线时唯一诚实的表达方式。
- 固定剧情走完之后进入**动态模式**，六种话题轮转（灯数进度 / 最近来过的人 / 光花数 /
  此刻在线人数 / 当前天光阶段 / 流星雨提示），永远不重复、永远不说谎。
- **底部对话卡**：打字机逐字出（点一下立即放完）、左侧身份牌、右下「继续」提示。
  对话时锁移动，空格/回车推进、ESC 关闭。
- **对话时镜头取「玩家与说话人」的中点并上抬 1.3 格** —— 否则站在你南边的 NPC
  一定被底部对话框压住：台词在屏幕上、人在框后面，是最廉价的一种不专业。
- 没聊过的人**头顶浮一个「…」**，远远就知道这个人有话要说。

### 光柱（新）
- 灯柱从「脚下一团光」升级为**九格高的竖直光柱**（外锥 + 亮芯，`lighter` 合成）。
  俯视视角严格说没有「竖直」，但夜里读得懂比物理正确重要：
  隔着半张地图、隔着雾，你能看见那边有人点过灯，并据此决定往哪走。

### 画风
- **NPC 从 Kenney 像素精灵改回矢量**。16px 硬像素放大之后，居民是画面上唯一一块马赛克，
  和程序化底图、矢量小物、矢量小人全冲突。现在靠低饱和的 NPC_TONE（旧铜/夜蓝/水青/苔绿）
  和头顶标记区分居民与同学，不靠画风。

### 修复
- **生产库缺 `shiguang_steles` 表**，石碑的石碑激活/秘境整条链路在线上一直是坏的
  （`/stele` 写入必失败，`enter` 每次走 catch 分支）。建表已补，重启后生效。
- 动态台词轮转从「灯数」开始，不再随机落在无关话题上。

## 3.0.0 · 大世界

从「五座小岛」扩建为「160×160 八岛云海大世界」，并把 v2 的骨架补成一个完整的小游戏。
地图面积 ×4，玩法系统 ×3，画面从纯矢量升级为「矢量地形 + Kenney 像素素材层 + 像素字」。

### 世界
- **八座生态岛屿**（启明/雾隐/星坠/拾贝/萤火泽/织花谷/望潮/霜屿）：每岛一套专属调色板
  （底图按「逐格岛号 → 生态双色」烘焙），树/石/花/蘑菇等道具按生态选取 Kenney 瓦片。
- **石板路网**：每岛「码头→岛心」主路 + 启明岛十字大道（T_PATH 新地形码），
  大道上有路灯（city 精灵）与石板缝，玩家顺着路走就不会迷路。
- **地标 ×8**：拾光灯塔（白朱横带 + 旋转双光束）、星陨坑（脉动星核 + 火盆）、
  雾隐巨树（6 倍大树精灵 + 萤光）、萤光环、贝壳拱门（悬贝轻摆）、望潮池（呼吸涟漪）、
  织花风车（旋转叶片）、霜岩（落雪微光）。全部「矢量底座 + Kenney 点缀」，
  瓦片加载失败自动退化，永不阻塞玩法。
- **氛围叙事**：海面碎光与漂移云影、鲸影（4~9 分钟一次横穿云海，带低鸣）、
  飞鸟（雁行掠过）、天光阶段全屏染色。

### 玩法
- **NPC 行者 ×4**：守灯人·栗 / 观星·遥 / 泽畔·芦 / 花匠·榔，服务端 2.2s 游荡节拍、
  11s 台词节拍（有玩家在附近才开口）；客户端用 Kenney 角色精灵绘制 + 白瓷台词气泡
  （像素字，超宽自动折行）。台词表随 terrain 下发，delta 里只传编号。
- **五座石碑**：走近 ≤2.5 格出现「触碑」情境动作；首触唤醒（+5 星屑），
  服务端落库并全服播报碑文；**全班集齐五座 → 秘境之门事件 + 「五碑之谜」成就**。
- **纸鸢快线**：码头情境动作 → 选岛面板 → 2 星屑跨岛；落地落在目标岛码头根部，
  自动揭开半径 8 圈迷雾；前端整屏云海过场（纸鸢摆动 + 云层上掠）。
- **逐岛钓星特产**：每个码头的渔获有 40% 概率锁定本岛特产池 ——
  「雾隐的海月、望潮的深水种」，八座岛的码头从此有了分别。
- **灯柱带建造者灯色**：enter/nearby 的灯柱 LEFT JOIN 出建造者的衣柜灯色，
  delta 同步 —— 夜里远远看去，灯柱是全班每个人的颜色。
- 星屑节点阈值 0.05（约 331 颗），光花上限放宽到世界 600 / 每人 40（可种在路边）。

### 体验
- **世界地图弹窗**：2px/格全图，未探索只留岛影；灯柱金点、光花彩点、地标白标、
  石碑紫标（未唤醒是空圈）、流星雨脉动环、同学与自己的位置、各岛岛名与探索率。

  名字牌、NPC 台词、地图岛名在 11px 下不再是一团抗锯齿灰。
- **新手引导第三页改写**为八岛玩法概览；帮助面板扩到九条（含快线/石碑/居民）。

## 1.1.0

操作与画面重做。1.0.1 虽然把「格子纸」修掉了，但界面仍然是「能跑就行」的样子：
左下四个方向方块、右下三个同样大小的文字按钮、顶栏一条通栏黑条，而画面本身
是一张水彩糊——草地均匀、沙滩是一条发白的宽带、树是几个暗斑。

- **方向键换成虚拟摇杆**：圆形底座 + 方向刻度 + 推力光带 + 玻璃帽。输出是连续矢量，
  按轴向吸附到四方向（服务端只认曼哈顿距离 1）；落在 45° 对角区时沿用本次拖动内
  上一次的方向，避免手指停在斜向时角色沿两条轴来回抽搐。死区取「比例」与「11px
  绝对值」中较大者——矮屏下摇杆会缩到 112px，纯比例的死区只剩 9px，
  手指一放上去就误走一步。
- **顶栏不再通栏**：改成从顶端淡出的渐变，世界从它底下透出来；品牌区两行
  （岛名 + 当前天象），资源改成一枚枚玻璃胶囊，右侧是图标按钮。
- **动作键改为三个圆形按钮**，沿 135° 对角线排开，最大的「采集」落在拇指自然落点；
  点灯消耗改由角标显示。可用时整颗按钮泛出属于自己的光。
- **图标全部改用内联 SVG**（stroke 风、24 栅格），逐节点 createElementNS 构建。
  原来的字符图标（✦ ◈ ?）在校园平板的系统字体里各家渲染不同，一排里只要有一个
  走了 emoji，整块 UI 就垮了。
- **地形底图从 5 提到 14 子像素/格**（1120×1120）。原来一格只有 5 个像素，贴到
  47px 的格子上等于放大 9 倍，所有高频细节都被抹成水彩。提到 14 之后底图仍然只做
  「材质」，高频交给矢量笔画——这是三层分工的前提。
- **海岸线改由掩膜等值线给出**：先把地形铺成 4 子像素/格的掩膜，做两遍可分离盒式
  模糊（sigma ≈ 0.9 格），再取等值线。颜色不再从「格子」取，形状才彻底脱离网格。
- **材质用双色插值，不用单色乘亮度**：乘法只能改明度、改不了色相，草地永远是
  同一种绿。改成「阴影色 ↔ 受光色」两点插值，受光偏黄绿、阴影偏蓝绿。
- **材质边界用噪声当阈值去切**：掩膜糊过之后是一条 0.75 格的斜坡，直接取样就是
  一圈软渐变（截图里那条平滑的褐色带）。这里不做插值，改用两层噪声（0.34 格 /
  0.14 格周期）当阈值线去切，边界才碎成毛边；成立的前提是斜坡够宽——
  所以掩膜必须先糊，再切。
- **湿沙**：紧贴水面的一圈压暗 36% 并偏冷。少了这一圈，沙滩和云海就是两块并排的
  色块，中间没有交接。
- **树改成预烘精灵**：一棵树要「叶瓣并集轮廓 → clip → 径向渐变 → 叶隙 → 左上漫射
  光」五步，逐帧画一帧七八十棵会吃光预算。按 dpr 烘 8 个变体，之后每棵只是一次
  drawImage。轮廓的关键是「瓣心落在外圈上」——外沿半径 = 瓣心距 + 瓣半径，
  瓣与瓣之间必然凹下去，叶缘才有缺口；再把整个剪影先填成高光色、用主体在右下偏移
  一点盖上去，左上就露出一道约 1px 的逆光边——树从草地上「立起来」全靠这道边。
- **角色改成俯视剪影**：原来画的是梯形袍 + 圆头，那是侧视剪影，贴在俯视地图上像
  剪贴画。现在肩是横向椭圆（肩宽 > 身长），帽顶压在上面，头肩之间有一道投影，
  朝向由帽沿朝前那一小段描暗给出——不画脸，人是一枚干净的棋子。提灯加了一小截
  手臂连回身体，孤零零一颗光点浮在旁边会被读成「地上有颗星屑」。
- **雾改成有体积的云**：未知区域原来是一层半透明靛蓝，在格子上做背景噪声，读作
  「没画完的暗角」。现在云体有明暗（噪声平方当云隙/云顶），边界用噪声推开等值线，
  贴着已探索区的一圈云头被月光照亮——它同时交代光源方向，并把视线收回岛上。
- **出生点南移到岛缘**：站岛中心时视野里全是草地，第一眼像俯视草地 demo；
  南移到 (40,48) 后视野下缘正好收在海岸上。视野改为 27 格宽 × 17 格高，
  海岸线、沙滩、云海三层同时进画面。
- 兼容：全部改用宿主令牌 `--radius-*` / `--motion-spring-*`，CSS 里不再有裸圆角、
  自造 cubic-bezier 与布局属性过渡；`market-review` 0 错 0 警。
- 修复：`.sg-root button` 的重置选择器（0,1,1）特异性高于 `.sg-act`（0,1,0），
  把按钮的边框和背景整体吃掉——上一版所有按钮其实都「没有壳」。
- 修复：心跳返回缺 `onlineCount` 时 HUD 会打出「undefined 人在岛」。

## 1.0.1

渲染层重写。1.0.0 在真实宿主里跑出来的画面是「格子纸」：沙滩一级级直角楼梯、
草地像马赛克棋盘、雾是一块块带缝的方格。根因不是配色，是「一格一个矩形」这个画法。

- **地形底图改为子像素颜色混合**：80×80 的格子预生成 5× 子像素图（400×400），
  相邻格按距离加权混合 RGB，交界是一条跨约 1 格的渐变带，不再是硬边。
  每帧只画一次 `drawImage`，比原来 300 多次 `fillRect` 更快。
- **海岸线加坐标扰动（domain warping）**：低频噪声把采样坐标偏开 ±0.5 格，
  格状边界弯成自然海岸线。扰动逐像素连续求值——早期版本查「每格一个偏移」的表，
  表在格界处跳变，等于把直角换成了另一种直角，白改。
- **雾改为子像素 alpha 图 + 3×3 均值模糊**：浓度用连续噪声，不再是每格一个
  27px 的深浅方块；边界也不再是一条几何直线。
- **新增地面装饰**：树（按低频噪声成林，空地处零星几棵）、岩石、沙丘纹、细草。
  纯客户端按格哈希推导，不占服务端状态、不影响碰撞。
- **角色重画**：斗篷改成上窄下宽的梯形，加肩线高光、呼吸浮动，右手侧加一盏提灯。
- **视野从 17 格放宽到 26 格**（格子 48px → 40px）：48px 下一格就是一级 48px 的
  台阶，扰动压不住；40px 时台阶退到细节尺度。
- 修复：接口路径多写了一层 `/api`（宿主 baseURL 已是 `/api`），表现为「地形为空」
  且不抛异常。
