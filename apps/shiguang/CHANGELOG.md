# 拾光群岛 · 更新记录

## 5.8.0 · 《夜语》与联机手感

**联机手感（本轮重点）**：把「明明在同一个班，看起来却慢半拍」这件事做实。

- **同步 5Hz → 10Hz**：远端玩家与怪物的采样间隔从 200ms 降到 100ms；位置改为「分段线性插值 + 段尾短外推」，晚到的包不再先停住、再瞬移一下（那就是「一卡一卡」的来源）。插值时钟跟随顿帧/子弹时间，慢镜头里远方实体也会慢下来。
- **命中/技能合包**：打怪的那一下不再单独发一次请求，而是跟着同一条 `/sync` 走（服务端先落位置、再结算、最后拍快照）。此前每打一下都要多等一个往返才轮到同步，战斗中最容易感到卡顿。
- **两条同步在途 + 乱序保护**：校园网抖动时节奏不被单条请求卡住；旧快照不会覆盖新状态，但旧快照里的事件（掉落/升级/灯塔）照收，奖励不丢。
- **进世界不再重复下载地形**：先拉 1KB 的 `terrain/meta` 校验版本，命中本地缓存就直接进；5.7.1 的旧缓存会因缓存版本升级（10）自动重拉一次。
- **服务端热路径减负**：灯塔进度加 2 秒短缓存（点灯即失效），去掉每次同步一次 SELECT；10Hz 下 40 人并发压测（约 300 请求/秒、1800 次同步）0 失败。

**《夜语》（v5.8 玩法）**：20 页夜语残页与守塔人日记同格，入夜才浮现（黄昏最后 15% 渐显）。长夜之主倒下后开启「守夜仪式」—— 全班到塔下举灯同守 60 秒（门槛按开始时在线人数取，中途离开有 3 秒宽限），天亮后点亮最后一盏灯并生成「灯火名录」。图鉴世界页签按区域显示昼/夜双面进度，未获得的夜语正文不下发（防剧透）。

**测试**：unit 1204 / api 112 / social 46 / farm 298 / stability 14 / visual 33 / live 22 全绿。

并修掉真机平板上的两处硬伤。改动只落在 `style.css` 与前端 8 个源文件，后端与业务数据零改动。

### 视觉：从「两套色板」回归一套
- **16px 地板**：`.sg5-btn/.sg5-btn-sm/.sg5-tab/.sg5-note/.sg5-sect/.sg5-farm-cell` 全部提到 16px，
  9px 的农具快捷键角标（1–6）与 dock 键位徽标一并补足 —— 中文点阵不再发虚，快捷键可读。

  （`--px-gold` / `--px-gold-2`），同屏金色配额 ≤3 处（面板标题 / 当前页签 / 唯一主按钮）。

## 5.3.0 · 把「种田」接回长夜

这一版按明确要求做**机制复用而不是重新发明**：参考《星露谷物语》及同类农场经营游戏的成熟设计，
交互、数值与系统结构贴近原作，优先保证 1:1 的可玩性与一致性。
v4 曾写过一版「星露谷骨架」（12 作物 / 7 天一季 / 体力 / 天气 / 好感），v5 重写成开放世界动作 RPG 时
整套经营循环被砍掉了 —— 这次把它接回来，并且接在**同一个世界、同一份存档、同一套像素 HUD** 上。

> 代码、程序化美术、中文文案、音乐素材全部自研；借鉴的是公开的游戏规则与数值体系，
> 不含原作的代码、图片、文本或音频。出处见 `market/NOTICE.md`。

### 核心循环（对齐原作 1.6 量级）

- **日历**：28 天一季 × 春夏秋冬，全班共享一本日历，游戏时钟 6:00→2:00。
  天气按天数**确定性**生成（服务器重启不会把今天的雨变成晴），雨天/雪天自动浇水；
  开局第一天强制放晴，先让玩家亲手浇一次水。
- **田**：镇南每人一块 12×8 的私有地。锄地 → 播种 → 每天浇水 → 隔夜长一节 → 收获。
  **33 种作物**按季节、生长天数、复收周期、单次产量、额外收获概率、种子价、售价、经验各自不同
  （防风草 4 天 / 20g / 35g，蓝莓 13 天且 4 天复收、一次 3 个，南瓜 13 天 / 320g，上古果实 28 天 / 7 天复收）。
  收成有普通 / 银 / 金 / 铱四档品质，肥料与耕种等级抬升品质概率；过季作物换季枯萎，温室免疫。
- **体力与农具**：基础 100 体力，五件农具各有铜 / 铁 / 金 / 铱四级升级（金币 + 矿石锭，隔天取货），
  升级后一次能处理多格 —— 和原作一样，升级的价值在范围而不是省力气。体力见底拒绝动作，
  睡觉或跨日回满，昏厥扣 10% 金币（上限 1000）。
- **钱**：背包 12→24→36 格、家里箱子、种子 / 动物 / 资材 / 扩容 / 扩建房子；
  **出货箱次日清晨统一结账**，也能即时卖；种子半价回收，不收的杂物一律不换钱。
- **五项技能**：耕种 / 采矿 / 采集 / 钓鱼 / 战斗，5 级与 10 级各选一次职业
  （农夫作物 +10%、牧场主畜产 +20%、渔夫鱼价 +25%、工匠加工品 +40%……）。

### 农场之外的生活

- **畜牧**：6 种动物，每天喂干草 + 抚摸涨好感，次日产出，好感高出大号产物，漏喂掉好感。
- **钓鱼**：服务端在甩竿那一刻决定鱼，客户端只玩「绿条」——按住上浮、松开下沉，

- **矿洞**：120 层、每 5 层电梯、铜→铁→金→铱按层段解锁，层里有怪与楼梯，打晕送回地面并扣钱。
- **镇上的人**：4 位现有 NPC 补上生日、礼物偏好与心事件文案；每天对话 +20、每周最多 2 次礼、

## 5.2.0 · 让房子长在地上，让「一起玩」有来有回

这一版只解决两件从 5.1 留下的实话：**房子像贴纸**、**社交像通知栏**。

### 建筑：同一个图层

5.1 的房屋是「立牌」—— 整栋房从占地底边往上画，屋顶探出画面，占地本身却是一块空地砖。
于是上排房子只看到墙（俯视）、下排看到尖顶（正面），四栋房像贴在四张不同的纸上。

- 改成 **3/4 体积**：屋顶压住 `w × h` 的占地，正面墙从占地南缘往下长，门/窗/招牌都在这面墙上。
- 屋顶重画成 **四坡顶**：屋脊是中间一条短线，四条戗脊连到四个檐角；后坡受光、前坡背光、
  左右坡再各差一档明度 —— 四个面一亮一暗，房子才是盒子而不是一块铺了瓦的地毯。
  瓦仍逐片铺，但四个坡的瓦缝各自错开，不会连成横贯屋顶的砖缝。
- **地面层独立一遍**：`drawStructureShadows()` 在实体之前统一画门前石台（错缝砖 + 磨损）、
  接触阴影、右下方向的落影与檐口投影。影子不会被站在前面的人盖住，房子也不再"浮"着。
- 排序锚点从「占地南缘」改成「墙脚」（`+1.18` 格）：站在门口的人画在墙之后，
  站在屋檐下的人被墙挡住。NPC 退到墙脚之外、稍偏门侧，名字牌不再压在屋檐上。
- 夜里窗光、门灯、炊烟按同一套几何重算，不会飘到墙外。

### 一起玩：从「能组队」到「有关系」

- **好友**：申请 → 同意 → 双向写入，不搞单向关注。列表带在线状态、所在区域、等级与距离。
- **羁绊**：一起打怪（安静累加）、扶起（+8）、回应互动（+2~5）都会攒点数，
  称号从「初识 / 同行 / 挚友 / 知己 / 莫逆」递进，跨称号才提示并进世界频道 —— 不刷屏。
  数据落在 `flags.bond`，双方各存一份，不新建表。
- **悄悄话**：点对点、60 字、900ms 节流、控制字符清洗；说话时对方头顶弹出像素气泡。
- **双人互动**：击掌 / 抱一下 / 一起跳舞 / 加油 / 行个礼 / 一起看星星，共 6 种。
  **必须对方「回应」才算成立**（3 格内、30 秒内），附近的人都能看到双人特效与飘起的符号。
  一个人单方面击掌不算互动 —— 这是这一版最想守住的边界。
- **队伍**：频道聊天、队长集结（地面闪一个旗标 90 秒）；组队/好友/互动邀请统一换成
  右下角可点的**邀请卡**（滑入 + 呼吸图标 + 接受/婉拒），不再是「按 P 接受」的一行 toast。
- **附近的人**：一个面板看到同屏同学，一键加好友 / 打招呼 / 组队 / 互动。点同学的小菜单同样补齐这些入口。

## 5.0.0 · 长夜（推倒重来）

v4 有 12 种作物、七章剧情、8 个地标 —— 但玩家能做的动作只有一个：**走过去，按一下**。
内容越堆越像填表。v5 从「动词」重新开始：先让一秒钟的操作好玩，再让一分钟、一小时、一周好玩。

### 手感（第一优先级）
- 移动有加速度与摩擦（不是瞬时启停）；攻击三段连击，第三段 ×1.8 并击退；
  翻滚 0.32 秒、前 0.22 秒无敌、冷却 0.6 秒；**完美闪避**（出招前 0.15 秒内翻滚）触发 0.4 秒子弹时间 + 下一击必暴击。
- 打击感：命中顿帧 60ms（暴击 90ms）、敌人白闪 + 击退、暴击放大飘字、屏幕微震、粒子溅射、受击红晕。

## 4.3.0 · 手感

「可玩性太少、重复的内容太多」——这两句说的是同一件事：

- 手动「采集」按钮保留（站着不动时用）
- 采空的区域走过不会再弹提示（会自动捡，但不打扰）

8 连击后 4 秒内移速 +60%（本地节奏，服务端 80ms 下限仍然兜底）。

- **萤火虫**：18 只贴着草面飘，暖黄、比星点大一点，只在灯火范围里绕。
- **零散小物密度 3.8% → 8%**：以前平均 26 格才有一簇草，走在草地上什么都没有。

### 帧时
29ms（改动前 28ms）。风的代价约 1ms，萤火虫可忽略。

### 下一版的方向（如果这版还是觉得没意思）
那说明问题不在手感，而在动词。下一步就该砍内容：12 种作物收回 3 种、
8 个地标收到 3 个，只留一个动词把它做深。

## 4.2.0 · 种子

4.1.0 只有一种作物：固定 2 星屑、固定 3 分钟、固定收 8。
它证明了循环能转，但没有「选」—— 种什么不是一个问题。

这一版把「种什么」变成真正的问题：**12 种，三档，时间换钱**。

### 三档作物
| 档 | 代表 | 成本 | 时长 | 收成 | 回报 |
|---|---|---|---|---|---|
| 一阶 · 快 | 星苔 / 萤草 / 露铃 / 风铃籽 | 2~8 | 1~3 分 | 4~20 | **2.0×** |
| 二阶 · 中 | 月见花 / 灯芯藤 / 潮汐穗 / 霜葡萄 | 12~36 | 4~7 分 | 38~124 | **3.2×** |
| 三阶 · 慢 | 珊瑚果 / 拾光麦 / 星陨果 / 长夜葵 | 60~220 | 15 分~2 小时 | 260~1100 | **4.8×** |

回报率随时长递增，于是「今天还有几分钟」成了唯一的决策依据：
课间就种星苔，晚自习前种拾光麦，周五种长夜葵。

### 交互
- **按「种花」打开种子面板**：12 行，按档分组，每行写清 价格 / 时长 / 收成 / **净赚**
- 净赚直接写出来 —— 让玩家心算 38−12 是在浪费他的注意力
- 星屑不够的种子整行压暗、点了会告诉你差多少
- 浇水按作物时长折算（每次 −15%，最多三次）：慢的作物浇一瓢更值钱
- 颜色即身份：一档青蓝、二档暖橙、三档紫金 —— 远远看一眼田里花的颜色，
  就知道那个人种的是快钱还是长线

## 4.1.0 · 作物

「种花」在这之前是一次性动作：种下去，它就一直开着，除了好看没有任何作用。
所以没人会种第二次 —— 一个按钮用过一次就死了。

这一版把它接进经济：种 → 浇水 → 收 → 换星屑 → 点灯。
星屑第一次有了「生产」而不只是「捡」。

### 变化
- 光花改为作物：种下 **2 星屑**，**3 分钟**成熟，收成 **8 星屑**

- **不新开按钮**：站在苗上是「浇水」，站在空地是「种」，站在熟作物上是「采集」
- **帮别人浇水**：收成时浇水的人分 1 星屑 —— 顺手帮个忙第一次有回报
- **只有主人能收**：别人的田不能拔，这是多人底线
- 收成是同步事件：服务端删行、客户端摘掉，别人也会看到那株消失

### 数值
| 项 | 值 |
|---|---|
| 种子成本 | 2 星屑 |
| 成熟时间 | 180 秒 |
| 每次浇水 | −40 秒（最多 3 次） |
| 收成 | 8 星屑（4 倍回报） |
| 帮忙浇水者 | +1 星屑 |

### 为什么先做这个
星露谷真正黏人的不是像素画，是「种→收→卖→扩」这条复利循环。
拾光群岛原来有 306 个可交互点，但只有一个动词：按一下，数字 +1。
作物是第一个有「时间成本」和「回访理由」的动作。

## 4.1.0 · 玩法深度 × 开放世界

4.0.0 解决了「没压力」，4.1.0 解决「没朋友、没纵深」：采集要有节奏、
同学要能互动、世界要有尽头。

### 玩法深度（节奏与决策）
- **连击采集**：10 秒内连续采集累计 combo。×2 起头顶浮字，×4 起 toast
  带连击数、音效随连击升调，×8 金字加码；连击加成同时回一点火
  （快节奏本身就有奖励）。服务端权威计连击，防刷。
- **灯柱升级**：站在一级灯柱旁花 5 星屑升到二级 —— 光照半径 4.2→6.0 格、
  光柱更高更亮、黑暗层的洞更大。全班的灯越用越值钱。
- **送火**：点同学（或点菜单）送 1 枚星屑（6 格内），TA 头顶炸一圈金光。
  星屑第一次变成「可以给出去的东西」。

### 同学交互（点人即菜单）
- **点同学打开菜单**：头像名、称号、距离坐标；两个动作 ——
  **跟随 TA**（贪心寻步自动跟在身边，任何移动打断、卡住/30 秒自动停）、
  **送一枚星屑**。Journey 的牵手语义，换成提灯的旅程。
- **同学罗盘**：屏幕边缘一枚枚灯色光点指向屏外同学，尾迹指向感、
  越近越亮；正在跟随的人带金圈锁定。看不见 ≠ 不存在。
- **入岛 / 离岛广播**：有人进岛全班横幅「XX 来到了群岛」，
  离岛轻提示，本地名单即时归真。

### 开放世界的边界
- **世界边缘界标**：160×160 世界的四角立起呼吸的灯桩，
  隔着整片夜海也看得见 ——「尽头有灯」是开放世界的安全感。
- **边缘提示**：走近边界出现流动的虚线描边与语境提示
  「云海之外，什么都没有」；帮助面板补「同 / 界」两条。

### 修复
- `updateLight` 引用了未定义的 `surge`（应为 `state.surge`），
  暗涌订阅路径上会炸掉整个渲染循环 —— 沙盘逐帧验证抓出。

## 4.0.0 · 灯火

3.1.0 的问题是：这个岛「有内容，但没有压力」。
走到星屑上按一下 +1，再走到空地上按一下立灯 —— 全程零决策、零风险、零节奏。
你说「玩起来没意思」，对的是：它是一张会动的画，不是一个游戏。

这一版把「你手里还有多少火」变成唯一的资源，同时让它接管三件事：
血量、视野、货币。世界的样子会跟着你的火一起变。

### 灯火（新 · 核心）
- **火会自己烧**：走路 0.95/秒、站着 0.30/秒。站着也在暗，挂机不等于安全。
- **视野就是火**：满火能看 10 格，火只剩一成时只能看 4 格。
  四周压黑不是后期叠的一层暗角，是「你还能看多远」直接画在屏幕上。
- **灯柱是唯一补给**：站在点亮过的灯 6 格内回 4.2/秒。
  ⚠️ **别人的灯一样管用** —— 多人关系不是靠聊天建立的，是靠「谁在这里点过灯」。
- **点灯要烧自己的火**（-22）：你把自己的命换成一块永久的安全区。
- **雾灵**：火低于 34% 开始出现，最多 4 只，1.15~1.5 格/秒朝你漂。
  玩家 3.8 格/秒，**永远跑得掉** —— 它逼你走，不逼死你。碰到一次偷 9 点火。
- **火灭**：全黑昏迷 3 秒，醒来原地只剩 45 火。不传送、不扣星屑：
  代价是时间和位置，不是资产。

### 主线第一次被看见
- 顶栏「长夜」改成「长夜 · 3/10」。`/terrain` 从 3.0 起就一直在返回
  `stages`，前端从来没接住 —— 于是「全班一起把灯点到 100 根、把天光推到
  拾光之海」这条主线，在界面上一直是隐形的。
- 点灯提示改成「离「晨光初现」还差 7 根」，差 3 根以内换成另一句。

### 世界重做（地图 / 配色 / UI）
- **8 座正圆岛 → 复合岛形**：每岛 3~4 个偏移圆瓣，取所有瓣中最深的归一化深度。
  地峡、内湾、半岛自己长出来；沙环按深度切，半岛尖端窄、宽阔处宽。
  原先每座岛的半径只差 ±12%，高空看是八个圆。
- **内陆湖**：启明岛与萤火泽各一处（`LAKE`，不可走、不可点灯）。
- **村道**：启明岛原来是 44 格正交十字（80,66→80,110 / 58,88→102,88），
  俯视是一条一直通到画外的宽带 —— 「城镇骨架」没做出来，先做出来一条跑道。
  现在是主街 + 四条斜支路，路面 1.84 格。
- **沙岸与土径分开成两套色**：上一版 sand 通道借用 `pathLit`（暖米色），
  而沙环占陆地 27% —— 全画面面积最大的暖色是「没人点亮的沙子」，
  灯反而比不过它。现在沙是冷褐、土径是暖褐，暖色只属于光。
- **UI 去面板化**：顶部 HUD / 小地图 / 摇杆 / 动作簇 / 对话卡全部拆掉
  深色玻璃卡片 + 圆角 + 阴影（那是 2020 年移动端模板语言，贴在手绘夜空上
  属于另一个世界）。改用字距（0.18~0.22em）+ 字号层级立住。
  动作键从六个等大彩圆 → 一个主键 + 两列圆心对齐。
- **灯塔**：比例 1:1.65 → 1:3.9。之前画出来是水塔。补拱门漏光、护栏平台、
  竖窗框、锥顶顶针，光束改橙黄三层扇形（一层三角形无论怎么调都是「一块均匀的雾」）。

### 树：五次试错的记录
1. 6 个圆瓣 → 花椰菜
2. 11 个小瓣 → 葡萄串
3. 5 个等分瓣 → 梅花
4. 正弦叠加大振幅 → 海星；小振幅 → 圆盘
5. **3 个不对称叶扇（每个 = 3 个随机旋转的椭圆）+ 每团自带小块亮面** ✅

结论写在这里，免得下次再走一遍：
- **用几何圆拼不出有机形状** —— 交角只有固定几档，眼睛三秒读出「是拼的」。
- **贴着轮廓的连续亮边 = 湿石头高光的固定读法**。叶子给的是断开的亮斑。
- **树的色相必须和草地的色相不同**，不能只是更暗 —— 更暗的草地就是石头。

## 3.1.0 · 岛上有人

3.0.0 的岛上住着四个人，但他们只是「会走路的随机广播器」：从公共台词池里抽一句、
11 秒一次、说完就忘。玩家走过他们身边，什么也不会发生。
这一版把居民改成了有记忆的人，并把「这个世界里来过别人」变成能被看见、被听见的东西。

### NPC 对话（新）
- **走近 4 格自动开口**，不用点、不用按键。走到哪儿都有一个人先说话。
- **每人一套专属剧情**，按见面次数推进；进度落库（`shiguang_npc_talk`），
  换设备、隔一周回来，她还记得你聊到哪儿。
- **初见先说世界的真话**：这段时间几个人上过岛、上一个叫什么、
  他最后停在哪个坐标、全班一共点了多少盏灯、离下一阶天光还差几盏。
  数字全部现算，所以每一句都是真的 —— 这是「多人大世界」在没有人在线时唯一诚实的表达方式。
- 固定剧情走完之后进入**动态模式**，六种话题轮转（灯数进度 / 最近来过的人 / 光花数 /
  此刻在线人数 / 当前天光阶段 / 流星雨提示），永远不重复、永远不说谎。
- **底部对话卡**：打字机逐字出（点一下立即放完）、左侧身份牌、右下「继续」提示。
  对话时锁移动，空格/回车推进、ESC 关闭。
- **对话时镜头取「玩家与说话人」的中点并上抬 1.3 格** —— 否则站在你南边的 NPC
  一定被底部对话框压住：台词在屏幕上、人在框后面，是最廉价的一种不专业。
- 没聊过的人**头顶浮一个「…」**，远远就知道这个人有话要说。

### 光柱（新）
- 灯柱从「脚下一团光」升级为**九格高的竖直光柱**（外锥 + 亮芯，`lighter` 合成）。
  俯视视角严格说没有「竖直」，但夜里读得懂比物理正确重要：
  隔着半张地图、隔着雾，你能看见那边有人点过灯，并据此决定往哪走。

### 画风
- **NPC 从 Kenney 像素精灵改回矢量**。16px 硬像素放大之后，居民是画面上唯一一块马赛克，
  和程序化底图、矢量小物、矢量小人全冲突。现在靠低饱和的 NPC_TONE（旧铜/夜蓝/水青/苔绿）
  和头顶标记区分居民与同学，不靠画风。

### 修复
- **生产库缺 `shiguang_steles` 表**，石碑的石碑激活/秘境整条链路在线上一直是坏的
  （`/stele` 写入必失败，`enter` 每次走 catch 分支）。建表已补，重启后生效。
- 动态台词轮转从「灯数」开始，不再随机落在无关话题上。

  47px 的格子上等于放大 9 倍，所有高频细节都被抹成水彩。提到 14 之后底图仍然只做
  「材质」，高频交给矢量笔画——这是三层分工的前提。
- **海岸线改由掩膜等值线给出**：先把地形铺成 4 子像素/格的掩膜，做两遍可分离盒式
  模糊（sigma ≈ 0.9 格），再取等值线。颜色不再从「格子」取，形状才彻底脱离网格。
- **材质用双色插值，不用单色乘亮度**：乘法只能改明度、改不了色相，草地永远是
  同一种绿。改成「阴影色 ↔ 受光色」两点插值，受光偏黄绿、阴影偏蓝绿。
- **材质边界用噪声当阈值去切**：掩膜糊过之后是一条 0.75 格的斜坡，直接取样就是
  一圈软渐变（截图里那条平滑的褐色带）。这里不做插值，改用两层噪声（0.34 格 /
  0.14 格周期）当阈值线去切，边界才碎成毛边；成立的前提是斜坡够宽——
  所以掩膜必须先糊，再切。
- **湿沙**：紧贴水面的一圈压暗 36% 并偏冷。少了这一圈，沙滩和云海就是两块并排的
  色块，中间没有交接。
- **树改成预烘精灵**：一棵树要「叶瓣并集轮廓 → clip → 径向渐变 → 叶隙 → 左上漫射
  光」五步，逐帧画一帧七八十棵会吃光预算。按 dpr 烘 8 个变体，之后每棵只是一次
  drawImage。轮廓的关键是「瓣心落在外圈上」——外沿半径 = 瓣心距 + 瓣半径，
  瓣与瓣之间必然凹下去，叶缘才有缺口；再把整个剪影先填成高光色、用主体在右下偏移
  一点盖上去，左上就露出一道约 1px 的逆光边——树从草地上「立起来」全靠这道边。
- **角色改成俯视剪影**：原来画的是梯形袍 + 圆头，那是侧视剪影，贴在俯视地图上像
  剪贴画。现在肩是横向椭圆（肩宽 > 身长），帽顶压在上面，头肩之间有一道投影，
  朝向由帽沿朝前那一小段描暗给出——不画脸，人是一枚干净的棋子。提灯加了一小截
  手臂连回身体，孤零零一颗光点浮在旁边会被读成「地上有颗星屑」。
- **雾改成有体积的云**：未知区域原来是一层半透明靛蓝，在格子上做背景噪声，读作
  「没画完的暗角」。现在云体有明暗（噪声平方当云隙/云顶），边界用噪声推开等值线，
  贴着已探索区的一圈云头被月光照亮——它同时交代光源方向，并把视线收回岛上。
- **出生点南移到岛缘**：站岛中心时视野里全是草地，第一眼像俯视草地 demo；
  南移到 (40,48) 后视野下缘正好收在海岸上。视野改为 27 格宽 × 17 格高，
  海岸线、沙滩、云海三层同时进画面。
- 兼容：全部改用宿主令牌 `--radius-*` / `--motion-spring-*`，CSS 里不再有裸圆角、
  自造 cubic-bezier 与布局属性过渡；`market-review` 0 错 0 警。
- 修复：`.sg-root button` 的重置选择器（0,1,1）特异性高于 `.sg-act`（0,1,0），
  把按钮的边框和背景整体吃掉——上一版所有按钮其实都「没有壳」。
- 修复：心跳返回缺 `onlineCount` 时 HUD 会打出「undefined 人在岛」。

## 1.0.1

渲染层重写。1.0.0 在真实宿主里跑出来的画面是「格子纸」：沙滩一级级直角楼梯、
草地像马赛克棋盘、雾是一块块带缝的方格。根因不是配色，是「一格一个矩形」这个画法。

- **地形底图改为子像素颜色混合**：80×80 的格子预生成 5× 子像素图（400×400），
  相邻格按距离加权混合 RGB，交界是一条跨约 1 格的渐变带，不再是硬边。
  每帧只画一次 `drawImage`，比原来 300 多次 `fillRect` 更快。
- **海岸线加坐标扰动（domain warping）**：低频噪声把采样坐标偏开 ±0.5 格，
  格状边界弯成自然海岸线。扰动逐像素连续求值——早期版本查「每格一个偏移」的表，
  表在格界处跳变，等于把直角换成了另一种直角，白改。
- **雾改为子像素 alpha 图 + 3×3 均值模糊**：浓度用连续噪声，不再是每格一个
  27px 的深浅方块；边界也不再是一条几何直线。
- **新增地面装饰**：树（按低频噪声成林，空地处零星几棵）、岩石、沙丘纹、细草。
  纯客户端按格哈希推导，不占服务端状态、不影响碰撞。
- **角色重画**：斗篷改成上窄下宽的梯形，加肩线高光、呼吸浮动，右手侧加一盏提灯。
- **视野从 17 格放宽到 26 格**（格子 48px → 40px）：48px 下一格就是一级 48px 的
  台阶，扰动压不住；40px 时台阶退到细节尺度。
- 修复：接口路径多写了一层 `/api`（宿主 baseURL 已是 `/api`），表现为「地形为空」
  且不抛异常。
