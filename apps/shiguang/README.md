# 拾光群岛 · Shiguang Isles（v3 · 大世界）

> 云海之上漂着八座岛。全班共用一张 160×160 的世界：你点亮的地方，别人也能看见；
> 每根灯柱都是点亮它的人的颜色。

一个 ClassIntra 市场应用（多人大世界 / MMO-lite）：服务端权威、实时同屏、
全班共建迷雾与天光。装完即用，不需要额外服务或外部密钥。

---

## 世界

| 岛 | 生态 | 去处 |
|---|---|---|
| **启明岛** | 草地 · 枢纽 | 拾光灯塔（旋转光束）、十字大道与路灯、四座院落、环岛广场 |
| **雾隐岛** | 青绿 · 雾林 | 雾隐巨树（冠上萤光）、密林与松径 |
| **星坠岛** | 岩地 · 高地 | 星陨坑（脉动星核 + 火盆） |
| **拾贝岛** | 暖沙 · 浅滩 | 贝壳拱门（悬贝轻摆） |
| **萤火泽** | 墨绿 · 沼泽 | 蘑菇环（萤光孢子） |
| **织花谷** | 暖绿 · 花田 | 织花风车（叶片慢转） |
| **望潮岛** | 珊瑚 · 潮池 | 望潮池（呼吸涟漪） |
| **霜屿** | 霜白 · 寒岛 | 霜岩（落雪微光） |

八岛由十条云桥连通（中央辐射 + 外岛环线），每岛一条伸入云海的码头；
石板路从每个码头铺到岛心 —— 顺着路走就不会迷路。

## 玩法

| 动作 | 说明 |
|---|---|
| **走** | **连续移动**（摇杆模拟量 / WASD，分轴滑墙碰撞，相机逐帧跟随 —— 不是走格子）；点击地面任意一格，小人沿路丝滑走过去；**点地面任意一格，小人自动沿路走过去**（摇杆/键盘随时打断）；石板路上有路灯与花坛 |
| **捡** | 星屑约 331 颗散布全图，站上去「采集」（90 秒重生）；**10 秒内连采有连击**：×2 起浮字、×4 起加量、×8 金字，连击也回一点火 |
| **点灯** | 3 星屑原地「点灯」，照亮半径 4 格，**全班永久可见**；灯柱是建造者的灯色；**5 星屑可升级到二级**（半径 6 格、光柱更高） |
| **同伴** | **点同学打开菜单**：跟随 TA（自动寻步跟在身边）或送一枚星屑（6 格内，TA 头顶炸金光）；屏幕边缘的灯色光点是**同学罗盘**，指向屏外的同学 |
| **种花** | 草地/路边按「种花」选种下地（12 种三档，1~14 天成熟，越慢越值钱）；**一天浇一瓢水、隔夜长一节、浇了才长**——全班同住一个 6 分钟一天的日历；熟了金光全开，收成变现，帮浇的人分一点 |
| **钓星** | 站码头抛竿，10 种星鱼按稀有度掉落；**每座岛的码头有自己的特产**，传说级全服播报 |
| **快线** | 码头搭纸鸢跨岛（2 星屑），落地自动点亮周围一圈 |
| **触碑** | 五座石碑藏在五座岛上，走近唤醒（+5 星屑）；**全班集齐五座触发秘境事件** |
| **漂流** | 脚下留一句话，路过的人能读到（每人 4 分钟一只） |
| **表情** | 挥手 / 比心 / 哼歌 / 打盹 / 欢呼 / 疑问，头顶白瓷气泡 |
| **居民** | 守灯人·栗、观星·遥、泽畔·芦、花匠·榔在各自岛上散步，走近了会搭话 |
| **天象** | 灯柱总数推进天光（10/30/60/100）；流星雨不定时落在某岛，星陨限时可采；**暗涌**不定时袭来（45 秒），全图灯柱变暗、火耗加速——回到灯边 |
| **边界** | 世界有尽头：160×160 云海之外什么都没有，四角立着呼吸的界标灯桩；有人进岛 / 离岛全班都知道 |

开场即**剧情演出《长夜之始》**（黑幕独白+镜头飞向灯塔摇回出生点+星群动画，替代教程）、开场后接**新手目标链**（走→采→灯→种→进镇，小地图金圈+屏幕边缘箭头全程指引）、另有：**相遇簿**（进岛相遇双向计数，交友的账本）、**季节节日**（每季首日种子半价）、**世界剧情《灯火纪》**（七章主线，拾光志收录，章节由全班推世界解锁）、**背包经济**（收获进包/钱庄卖出/面对面送果实材料）、**砍树挖矿**（斧头矿镐、材料入包）、**NPC 好感度**（送礼攒好感：陌生→熟识→知己）、**季节轮换**（7 天一季，作物分季播种）、**240×240 开放大世界**（跨班 100+ 人同服）、**拾光镇商店街**（种子铺/衣帽店/钱庄三位店主 NPC，走近对话即开店）、**宅基地**（人人有农舍木牌）、**学元体系**（同学菜单面对面赠学元，走平台赠送学元通道）、**星露谷骨架**（右上时钟表盘 + 天气骰子 / 右下体力条 / 底部锄头水壶种子镰刀工具栏 / 夜晚睡觉结算与熬夜惩罚）、任务（引导链 6 步 + 每日 3 条）、成就 13 枚、拾光衣柜（帽子/提灯/称号）、
拾光录图鉴、世界地图（探索率与全班痕迹）、拾光明信片（当前画面合成，可分享）、
程序合成音效（可选）、鲸影与飞鸟的环境叙事。

## 开发要点（市场应用通用）

本应用**不过 Vite 构建**，源码直接下发到浏览器。必须遵守：

1. **全 ES5** —— 禁 `const`/`let`、箭头函数、模板字符串、`?.`、`??`、`class`、`async`
2. **实时走 SDK** —— `context.data.realtime`，禁止直接 `new WebSocket()`
3. **存储加命名空间** —— `context.data.storage`（自动 `ci:app:shiguang:` 前缀）
4. **CSS 避开 Chrome 84+ 特性** —— 不用 flex `gap`、`:is()`、`aspect-ratio`、`@container`；
   圆角一律 `--radius-*` 令牌，曲线一律 `--motion-spring-*` 令牌
5. **回收四类资源** —— 监听器 / 定时器 / 实时订阅 / DOM，全部经 `context.app.onDestroy`

回滚成旧版（v3 开发时真实踩过一次，全量源码靠备份重建）。

## 已知取舍

- **不用独立进程 / 自建 WebSocket**：进程反代只支持 HTTP，宿主已有全局 WS，
  复用 `realtimeBus` 少一条连接还自带长轮询降级。
- **地形不在前端重算**：`world.js` 是唯一真相，两端各写一份必出「屏幕上亮着、
  站上去采不到」的错位。
- **不接学元**：星屑是应用内资源，独立表，避免污染班级财政口径。
- **不配 `rateLimit`**：平台限流键是 `IP+path`，全班同一 NAT 出口会被整班锁死；
  改为应用内按 `user_id` 节流。
- **Kenney 瓦片是增强层**：加载失败（离线/老内核）时道具层自动退化，
  世界仍是完整的矢量地形 —— 素材层永不阻塞玩法。
- **像素字只进画布**：HUD 仍用系统字体栈（果风玻璃语言）；
  画布里的名字牌 / 台词 / 岛名用 Unifont EX，小字号下比抗锯齿灰字清晰得多。
- **接口路径不带 `/api`**：宿主 axios baseURL 已是 `/api`（v1 真实事故）。
- **画布尺寸不能只测一次**：`ResizeObserver` + 低频兜底轮询（v1 真实事故）。
- **terrain 客户端缓存 1 小时**：v2 曾用 24h，版本升级后旧地形多活了一天。
