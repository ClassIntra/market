# 拾光群岛 · 长夜（v5）

> 全班同在一片开放大世界里冒险。白天探索、打怪、攒材料；入夜后长夜从雾里涌出来，
> 大家回到灯边一起守夜。**你点亮的每一座灯塔，全班的世界都会变亮。**

一个 ClassIntra 市场应用：俯视角像素动作 RPG（塞尔达式的探索 + Hyper Light Drifter 式的战斗手感
+ 同一张地图上的全班联机）。装完即用，不需要外部服务或密钥。

旧版（v4.14「云海群岛」）保留在 git `a9b3e2c`，随时可回滚。

## 一分钟上手

| 操作 | 键 | 触屏 |
|---|---|---|
| 移动 | WASD / 方向键 | 左半屏拖动（虚拟摇杆） |
| 攻击（三段连击） | J / 空格 | 右下大按钮 |
| 翻滚（前 0.22 秒无敌） | K | 翻滚键 |
| 技能（灯火回旋） | L | 技能键 |
| 交互（开箱 / 传送石 / 说话） | E | 交互键 |
| 角色 / 背包 / 地图 / 图鉴 / 天赋 | C / B / M / V / T | 左下角图标 |

**完美闪避**：在怪物出招前的 0.15 秒内翻滚 → 0.4 秒子弹时间 + 下一击必暴击。
每个怪物都有一条「红色预警」（扇面 / 直线），照它躲。

## 世界

- **256×256 格**（16px 一格）分 6 个区，从中心向外：拾光镇 → 晨光草原 → 雾隐林 → 萤火泽 → 星坠岩 → 霜屿，东北角飞地是终局区**长夜之心**。
- 每区一座**区域灯塔**：走到塔前会唤醒守护者，打倒它 → 灯塔亮起 → 整片区变亮、剧情推进一章。
  **灯塔是全服进度**（任何人点亮，全班都亮）。
- 昼夜：一天 12 分钟，全班共享。入夜后视野收窄到灯光范围，幽灵从雾里涌出来，掉落 ×1.5。
- 每个区有传送石（点亮后可互传）、宝箱（个人进度，一人只能开一次）、洞窟与野怪点。

## 成长

等级 1~30；每 3 级 1 点天赋（剑 / 影 / 灯 三条线）；武器 5 类手感（剑 / 长枪 / 双刃 / 法杖 / 战锤）；
装备 3 槽（武器 / 护符 / 披风）× 5 档稀有度（白绿蓝紫金）× 10 种随机词条；镇上铁匠可重铸词条（星屑的主要出口）。

## 经济

局内货币「星屑」：打怪、开箱、卖装备获得；用于锻造、买药、买灯油。**不出售任何战力**。
v4 的星屑按 1:1 折算（上限 500）带入 v5。

## 技术

- **前端**：单张 Canvas 2D，16px 瓦片 × 整数缩放（按屏幕 3~4 倍），地形按 32×32 分块烘焙离屏缓存，
  树 / 岩 / 房屋 / 灯塔按脚底 y 排序与角色一起画（走到树后真的会被挡住）。
  全 ES5，Chrome 80 基线（校园平板）。
- **后端**：Express 路由 + 10Hz 世界模拟 tick（怪物 AI、刷怪、昼夜、守护者），按视野半径下发实体。
  **怪物服务端权威**：AI / 生命 / 掉落都在服务端；玩家命中由客户端判定后上报，服务端校验距离、频率与伤害上限
  —— 手感零延迟，结果不可伪造。
- **同步**：客户端 5Hz `POST /v5/sync`（位置上报 + 视野快照 + 我的事件），位置有速度上限校验；
  低频世界事件（灯塔点亮、守护者苏醒）走宿主 realtimeBus 定向广播。
- **存档**：SQLite `shiguang5_*` 五张表（players / chests / towers / boss_kills / feed），
  玩家状态内存为准、每 5 秒批量落库。

### 目录

```
backend/v5/          服务端
  config.js          数值（速度、冷却、掉落率…都在这儿调）
  data.js            区域 / 21 种怪物 / 6 个守护者 / 武器 / 词条 / 天赋 / 技能
  worldgen.js        确定性世界生成（地形 + 区域 + 地标 + 刷怪点）
  sim.js             10Hz 模拟：AI、投射物、命中校验、昼夜
  loot.js            装备生成与属性合成
  store.js           SQLite 存档
  routes.js          HTTP 世界服务（enter / sync / hit / chest / equip / talent …）
frontend/
  entry.js           构建产物（由 v5/src/*.js 拼接，不要直接改）
  style.css          HUD 样式（全部 sg5- 前缀，八档圆角令牌）
  v5/src/            前端源码，按系统切分：
    00_frames.js     图集帧表（gen-frames.mjs 从 atlas.json 生成）
    01_core 02_audio 03_world 04_landmarks 05_player 06_data
    07_entity 08_mobs 09_ui_hud 10_ui_panels 11_net 12_boot
  v5/atlas.png       图集（263 个精灵，来自 Ninja Adventure，CC0）
  v5/music v5/sfx    BGM 11 首 / 音效 30 个
test/
  v5-unit.mjs        纯逻辑自测（地形连通性 / 掉落 / 伤害上限 / AI）1121 项
  v5-api.mjs         接口联调（内存库，不碰生产）50 项
  v5-visual.mjs      真 Chrome 验收（隔离宿主替身）截图 + 控制台断言
  v5-live.mjs        生产实例验收（真 cookie / 真 SDK / 真路由）
```

### 构建 / 验证

```bash
node frontend/v5/gen-frames.mjs     # 只有换图集时才需要
node frontend/v5/build.mjs          # src/*.js → entry.js
node test/v5-unit.mjs               # 纯逻辑
node test/v5-api.mjs                # 接口（需系统 Node：better-sqlite3 ABI 137）
node test/v5-visual.mjs             # 视觉（自带隔离服务器 + 无头 Chrome）
```

验收标准是**真浏览器里的截图与控制台断言**，不是「读一遍代码觉得对」。
