# 拾光群岛 v5「长夜」· 设计文档

> 状态：设计定稿，按里程碑实施。旧版（v4.14）保留在 git `a9b3e2c`，随时可回滚。

## 0. 为什么推倒

v4 有 12 种作物、七章剧情、8 个地标、5 座石碑……但玩家能做的动作只有一个：**走过去，按一下**。
内容越堆，越像在填表。v5 从「动词」重新开始：先让一秒钟的操作好玩，再让一分钟、一小时、一周好玩。

## 1. 一句话

**全班同在一片开放大世界里冒险。白天探索、打怪、攒材料；入夜后长夜从雾里涌出来，大家回到灯边一起守夜。
世界被照亮的每一寸，都是全班一起打下来的。**

定位：俯视角像素动作 RPG（参考《塞尔达：众神的三角力量》的探索 + 《Hyper Light Drifter》的战斗手感 +
MMO 的同服世界事件）。不做 3D，不做氪金，不做排行榜焦虑。

## 2. 四层循环（每一层都要单独好玩）

| 时间尺度 | 循环 | 好玩在哪 |
|---|---|---|
| **1 秒** | 移动 → 读前摇 → 翻滚躲开 → 反击三连 | 怪物攻击有红色预警，躲开有无敌帧和「完美闪避」慢动作；打击有顿帧、击退、震屏、飘字 |
| **1 分钟** | 遭遇一群怪 → 清场 → 开宝箱 / 解机关 → 发现下一处 | 每个区有不同怪物组合，逼你换打法；宝箱位置有视觉引导 |
| **1 小时** | 推进一个区 → 打区域守护者 → 点亮区域灯塔 → 解锁下一区 + 一章剧情 | 灯塔点亮后整片区变亮、怪变少、出现 NPC 和商店——看得见的进展 |
| **1 周** | 等级 / 装备 / 技能 / 图鉴 / 全班一起推进的「长夜潮汐」世界事件 | 全班共享世界进度；每周一次世界 Boss，所有在线的人一起打 |

## 3. 核心动作（手感是第一优先级）

- **移动**：摇杆模拟量 / WASD，8 向，加速度 + 摩擦（不是瞬时启停），速度 5.2 格/秒。
- **普攻**：J / 攻击键。三段连击（横斩 → 回斩 → 突刺），第三段伤害 ×1.8 并击退。攻击时会朝最近敌人轻微吸附转向（自动瞄准，平板友好）。
- **翻滚**：K / 翻滚键。0.32 秒，前 0.22 秒无敌，冷却 0.6 秒。**完美闪避**：在敌人攻击判定前 0.15 秒内翻滚，触发 0.4 秒子弹时间 + 下一次攻击必暴击。
- **技能**：L / 技能键，消耗「灯火」（蓝条，攻击命中回复）。初始技能「灯火回旋」：周身一圈光刃。后续可解锁/切换。
- **交互**：E / 交互键。对话、开箱、拾取、点灯。
- **打击感**：命中顿帧 60ms、敌人白闪 + 击退、暴击放大飘字、屏幕微震、粒子溅射、受击红晕。

### 敌人设计原则
每种敌人都要有**可读的前摇**和**一个逼你改打法的特点**：

| 敌人 | 区域 | 行为 | 逼你做什么 |
|---|---|---|---|
| 史莱姆 | 晨光草原 | 蓄力后跳扑 | 学会看前摇翻滚 |
| 竹精 | 晨光草原 | 慢、血厚、挥击范围大 | 学会打完就退 |
| 独眼 | 雾隐林 | 远程，发射光弹 | 学会走位逼近 |
| 蘑菇 | 雾隐林 | 死后炸孢子云 | 打完别贴脸 |
| 蛇 | 萤火泽 | 快速突进 | 完美闪避练习 |
| 骷髅 | 星坠岩 | 有盾，正面减伤 | 绕背 |
| 幽灵 | 长夜（夜间全图） | 穿墙，怕光 | 往灯边打 |

精英怪 = 同种更大 + 金色描边 + 一个额外招式。Boss 有阶段和弱点窗口。

## 4. 开放世界

- 地图 256×256 格（16px 一格），**6 个区**从中心向外环绕，越远越难：
  拾光镇（安全区）→ 晨光草原 → 雾隐林 → 萤火泽 → 星坠岩 → 霜屿 → 长夜之心（终局）。
- 每个区有：1 座**区域灯塔**（被长夜占据，打守护者后点亮）、2~3 个**宝箱谜题**、1 个**洞窟**、若干 **NPC 支线**、**传送石**。
- **区域灯塔是全服进度**：任何人点亮后，全班的世界里这个区都变亮——这是多人的意义所在。
- 战争迷雾：没去过的地方在地图上是黑的；探索率进图鉴。

## 5. 昼夜与「长夜」

- 一天 12 分钟（白天 8 分钟、黄昏 1 分钟、夜晚 3 分钟），全班共享。
- **入夜**：视野收窄到灯光范围，幽灵从雾里涌出，掉落 ×1.5。灯塔和玩家点的营火是安全区。
- **长夜潮汐**（世界事件，约每 40 分钟一次）：某个区被长夜反扑，全服广播，到场的玩家一起守灯 3 分钟，按贡献结算。

## 6. 成长

- **等级**：1~30，每级 +生命/攻击，每 3 级一个**天赋点**（三条天赋线：剑 / 影 / 灯）。
- **装备**：武器、护符、披风三槽。稀有度 白/绿/蓝/紫/金，带随机词条（暴击、吸血、灯火回复、移速……）。
- **武器种类**：剑（均衡）、长枪（距离远、慢）、双刃（快、伤害低）、法杖（远程、耗灯火）——各自改变普攻手感。
- **锻造**：拾光镇铁匠用材料打造 / 重铸词条。
- **图鉴**：怪物、装备、区域、剧情信件，集齐有称号。

## 7. 剧情

主线《灯火纪》七章，由**区域灯塔**推进（全班的进度推动剧情，不是个人）：
长夜降临的真相、先行者留下的信、守灯人栗的秘密……每章点亮时全屏章节卡 + 镇上 NPC 台词更新。
支线：每个 NPC 一条 3 步小故事（找东西 / 打特定怪 / 带话），奖励独特装备或外观。

## 8. 多人

- **同服世界**：所有在线玩家同一张图，实时看见彼此移动、攻击、受击。
- **怪物服务端权威**：怪物 AI、生命、掉落都在服务端模拟（10Hz 推送）；玩家的攻击由客户端判定命中后上报，服务端校验距离与冷却。手感零延迟，结果不可伪造。
- **组队**：点同学 → 邀请组队（最多 4 人），共享经验、队友在小地图上标出、倒地 8 秒内可被队友扶起。
- **世界 Boss**：周末与长夜潮汐时刷新，伤害榜结算、人人有份。
- **社交**：表情、快捷语、赠送材料、相遇簿。

## 9. 经济与学元

- 局内货币「星屑」：打怪、开箱、卖材料获得；用于锻造、买药水、买外观。
- 学元只走平台赠送学元通道（沿用 v4.6 的 giftGrant），用于少量里程碑奖励；不出售任何战力。

## 10. 技术架构

- 前端：单张 Canvas 2D，16px 瓦片 ×整数缩放（按屏幕自适应 3~4 倍），离屏缓存地形分块；ES5，Chrome 80 基线。
- 后端：Express 路由 + 一个 10Hz 的世界模拟 tick（怪物 AI、刷怪、昼夜、事件）；按区块（32×32）只推送玩家附近的实体。
- 存档：SQLite 表 `shiguang5_*`（不碰 v4 表，迁移时把 v4 星屑折算成 v5 起始星屑）。

## 12. 里程碑（每一步都可玩、都在真浏览器验证后交付）

1. **M1 手感**：一个区（晨光草原 + 拾光镇）、移动/普攻三连/翻滚/完美闪避/技能、3 种怪 + 1 精英、掉落/升级、多人同屏同打、昼夜。
2. **M2 世界**：6 个区完整地图、区域灯塔与守护者、宝箱谜题、洞窟、传送石、小地图与大地图。
3. **M3 成长**：装备与词条、4 种武器、天赋树、锻造、图鉴。
4. **M4 一起玩**：组队与扶起、长夜潮汐、世界 Boss、社交。
5. **M5 故事**：七章主线、NPC 支线、章节演出、音乐音效全量接入。
